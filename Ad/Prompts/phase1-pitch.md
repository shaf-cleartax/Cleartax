Phase 1 — Pitch concepts
Read this before pitching. The goal of this phase is to give the user a genuine choice of
creative directions in plain text — do not render anything yet.
When the user asks for an ad, first understand the brief: what's being promoted (which
country/countries, which mandate or moment, what the CTA goal is). Ask at most one quick
clarifying question only if the brief is genuinely unclear; otherwise infer sensibly.
Then present 5 distinct concepts as a short text list (no rendering yet). Each concept =
a different creative angle, not just a different color. For each, give:

Concept name (2–4 words)
Headline (the actual Nohemi headline copy, using the two-tone split where it helps)
Subhead (Gilroy, optional)
CTA (pill label, or "no CTA")
Mood (A warm / B light / C dark — palette language for text/CTA)
Background (one of the bundled gradients — pick from assets/backgrounds/INDEX.md, e.g. crimson-flare)
Hero photo (one line describing the photographic hero image to shoot/source — the subject,
setting, and mood; this is the ad's main image)

Keep the five concepts meaningfully different: vary the angle across urgency/deadline,
coverage/credibility, aspirational/future, cost-of-inaction, and product/ease — and vary the
mood so the set isn't monochrome. End by asking which one to build (and invite tweaks to copy,
mood, or hero).
