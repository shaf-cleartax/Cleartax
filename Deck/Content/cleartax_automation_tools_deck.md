# Automation Tools for ClearTax

## Automating the Way We Create

------------------------------------------------------------------------

## Slide 1: The Current State and the Problem We're Trying to Solve

### Growing Teams Come With Growing Responsibilities

As a growing company, each teammate manages multiple responsibilities.

To achieve the desired output, we often need to coordinate with and rely
on one another. While collaboration is important, it can sometimes lead
to delays.

The person you depend on may also be handling multiple priorities, which
can slow down your work, especially when something needs to be published
quickly.

### So, We Built Automation Tools

We created tools that can automate much of this work, reduce the time
required to complete it, and hopefully take over more repetitive tasks
in the future.

------------------------------------------------------------------------

## Slide 2: What Can We Automate Today?

### Automation We Can Put Into Real Use

We can currently automate the creation of:

-   Ads
-   Websites
-   Assets
-   Decks

------------------------------------------------------------------------

## Slide 3: How Can It Help Us?

### Reduce the Work. Reduce the Wait.

Automation can help reduce our workload and cut down waiting time.

It allows us to create designs immediately and generate outputs that are
ready for publishing.

------------------------------------------------------------------------

## Slide 4: How Can We Use It?

### Where We Are Today

Currently, each automation requires us to download a package and run it
through Claude Code.

### Where We're Heading

We are working towards making the process more user-friendly.

The goal is to enable everyone on our team to use these automations
directly through the Claude app instead of relying on the terminal, as I
currently do.
