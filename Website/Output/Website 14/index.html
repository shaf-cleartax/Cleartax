ClearTax Design System

Quality foundations and a small, deliberate set of brand elements — so everything we ship looks like it came from the same place. Navy and off-white do the heavy lifting; lime and violet earn their moments.

Principles

  • Restraint over decoration. If a layout starts looking like a rainbow, we've gone too far.
  • One job per colour. Violet means "click me". Lime means "look here". Nothing else competes.
  • Space is a material. Off-white covers half of any layout on purpose.
FoundationsLogo

Logo

Our wordmark is the clearest signal of who we are. Keep it clean, keep it legible, and give it room to breathe.

Download logo files↓

Lockups

Two lockups cover every case — white on dark, navy on light. There is no third variant.

Clear space and sizing

Clear space

Keep clear space equal to the height of the wordmark on all sides. Never let other elements crowd it.

Minimum size

Never scale below 80px wide on screen, or 20mm wide in print — legibility comes first.

Usage

Do

  • Use the white mark on navy or dark photography
  • Use the navy mark on off-white or light backgrounds
  • Scale the logo proportionally

Don't

  • Stretch, skew, or rotate the wordmark
  • Recolour it outside navy or white
  • Place it on a busy or low-contrast background

Colour ratios

Off-white covers the majority of any layout as empty space, navy carries the primary brand voice, violet appears on calls to action, and lime is the sparing accent that highlights key elements.

  • Off-white 50%
  • Navy 35%
  • Violet 10%
  • Lime 5%

Three tiers

Tokens layer. Reach for the highest tier that answers your question — it keeps product code insulated from palette changes.

  1. 1
    Primitives — the raw ramps (--ct-color-indigo-500). Never reference these in product code.
  2. 2
    Semantics — intent, not hue (--ct-color-content-primary). This is the tier you should be using.
  3. 3
    Component — per-component overrides (--ct-button-secondary-hover) for cases semantics can't express.

Naming

Every token follows --ct-<domain>-<path>, lower-kebab. The Figma path maps straight onto it.

Figma nameCSS variableValue
Content / Primary--ct-color-content-primary#05022A
Font / Size / md--ct-font-size-md18px
Space / L--ct-space-l16px
Width / M--ct-border-width-m2px

Formats in the bundle

  • cleartax-tokens.cssCSS custom properties on :root — drop in and go.
  • cleartax-tokens.scssSCSS variables, $ct-….
  • cleartax-tokens.jsES module, grouped by category.
  • cleartax-tokens.jsonNormalized JSON for any pipeline.
  • figma/*.jsonThe untouched Figma exports, W3C token shape.

Tip: every row here is a button — click to copy. Token rows give you the CSS variable; swatches on Primitives and Color give you the hex.

Known gaps in the source

Flagging these so nobody burns an afternoon on them. They're upstream data issues, not site bugs.

  • Surface.L0–L6 are all #FFFFFF. Elevation isn't differentiated yet, so the seven surface tokens are interchangeable today.
  • Two ramps repeat a value. Destructive.400/500 are both #EF4444, and Blue.300/400 are both #2123FF.
  • Radius / Circle is 50 in Figma. Published as 50% here, since that's what makes a circle in CSS.
  • One placeholder token was excluded. Typography.Icon has the literal value “String value”, so it's left out of the generated formats.

Usage

The system, assembled. This is the live Rebrand prototype — click through it to see how colour, type, icons, and spacing behave together in a real product flow rather than as isolated specs.

Open prototype↗ Open Figma file↗

Interactive prototype

Click hotspots to navigate, exactly as a user would. The embed loads for anyone signed into Figma with access to the Rebrand file; if you see a permission screen instead, set the file to “Anyone with the link can view” — or use Open prototype above.

What to look for

  • Off-white carries the layout. Roughly half of every screen is empty space — that's deliberate, not unfinished.
  • Violet only ever means "act". Track it through the flow: it appears on the primary action and nowhere else.
  • Lime punctuates, never decorates. One highlight per screen at most.
  • Navy does the talking. Headlines and body copy sit in navy on off-white, not pure black on white.
  • Icons keep their white chip. Same circle, same single-colour line, at every size.

Source of truth

The prototype lives in the Rebrand Figma file. Anything that contradicts the token pages here should be treated as drift — the tokens win, and the file gets corrected.
